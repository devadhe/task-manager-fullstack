# 🚀 Full Stack Task Manager

A modern full-stack task management web application built using Node.js, Express, MongoDB, and Vanilla JavaScript.

---

## 📌 Features

- ✅ Add, Edit, Delete Tasks
- 🌙 Dark Mode
- 🎯 Status Management (Pending / Completed)
- 🔍 Real-time Updates
- 💾 Persistent Database (MongoDB)
- 📱 Responsive UI
- ⚡ RESTful APIs

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
